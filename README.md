# 三维分析法 · 选题改造 Agent Skill

> 把一个模糊的选题，一步步挖成一批"用户真有需求"的选题。

这是一个可以直接装进 AI 工具里跑的 Skill。它不会一口气甩给你几十个标题，而是像老师一样一问一答，逼着你自己把选题背后用户真正的痛感、情绪、欲望挖出来，最后再组合成一片选题树。

MIT 协议，免费使用、修改、分发、商用。

---

## 它到底在干什么

一句话：**把"我想讲什么"，换成"用户为什么非看不可"。**

三个维度，逐层往下：

**第一维 · 用痛苦重新定义人群**
身份标签（宝妈 / 30-40 岁 / 小个子）不能用，因为它定位不了内容——同一个标签下的两个人，对同一件事的看法可能完全相反。所以换一条路：**人因痛苦而行动，找不准人群就找痛苦**，找这件事上谁最难受。再往下切一刀：痛苦是**感受**不是事实——不是"胖的人"，是"**觉得**自己胖的人"。

**第二维 · 情绪溯源**
情绪是探针，不是答案。"焦虑、自卑、迷茫"这些词本身没有价值，有价值的是顺着它往下追：
情绪 → 他在怕什么（具体的事）→ 这件事最后意味着什么（面子 / 健康 / 安全 / 认可 / 掌控 / 性价比）。
追到底的标志是：同一拨人**裂开**成动机不同的几拨——表面都是"觉得自己收入低"，一拨人要面子，一拨人要能力被认可。

**第三维 · 需求 × 价值类型**
真需求挖出来了，再决定给他什么：
- 情绪价值：把责任挪走、消解比较压力、重新归因给认同
- 实用价值：针对某个具体恐惧，给决策标准 / 方法 / 清单

故事、观点、价值观不是第四个维度，它们只是情绪价值的**包装形式**。

**组合**：一个被具体化的需求 × 一种价值类型 = 一条新选题。不同需求 × 不同价值，就是指数级分叉的选题树。批量出，挑着用。

**收尾**：帮你分清三件事——选题（后台真正在聊的内核）、钩子（第一秒让人停下的那句话）、脚本（怎么把价值交付完）。很多人以为自己脚本写不出来，其实是选题这步需求没想明白。

## 装到你的 AI 工具里

原理都一样：把 `skills/sanwei-topic-analysis/` 整个文件夹放进工具的技能目录，然后重启。

### 方式 A：下载 ZIP（不需要装任何工具）

1. 打开本仓库页面
2. 点绿色 **Code** → **Download ZIP**
3. 解压到任意位置
4. 把 `skills/sanwei-topic-analysis` 文件夹复制到下面表格里对应的目录

### 方式 B：命令行

```bash
git clone https://github.com/lizhi903993904-blip/sanwei-topic-analysis.git

# Mac / Linux —— Trae、豆包 Mac App 用这个
mkdir -p ~/.agents/skills
cp -R sanwei-topic-analysis/skills/sanwei-topic-analysis ~/.agents/skills/
```

### 各平台目录对照

| 工具 | 技能目录 |
|---|---|
| Trae（Mac/Linux） | `~/.agents/skills/` |
| 豆包 Mac App | `~/.agents/skills/`（与 Trae 共用） |
| WorkBuddy AI | `~/.workbuddy-ai/skills/` |
| Claude Code | `~/.claude/skills/` |
| Codex | `~/.codex/skills/` |

Windows（以 Trae / 豆包为例）：

```powershell
mkdir -Force "$env:USERPROFILE\.agents\skills"
Copy-Item -Path "skills\sanwei-topic-analysis" -Destination "$env:USERPROFILE\.agents\skills\" -Recurse
```

### 装完怎么验证

重启工具，输入一句：**"帮我改选题：梨形身材别买这三种裙子"**

- 它会先跟你确认这算不算一个选题，然后一个环节一个环节往下问 → 装成了
- 它直接甩给你一堆标题 → 没加载上，回到"装失败排查"

### 装失败排查（按这个顺序查）

1. **目录多套了一层**：必须是 `~/.agents/skills/sanwei-topic-analysis/SKILL.md`，不能是 `.../sanwei-topic-analysis/sanwei-topic-analysis/SKILL.md`。工具只认技能目录第一层的 `SKILL.md`。
2. **目录名和 `name` 字段不一致**：`SKILL.md` 头部 `name: sanwei-topic-analysis` 必须和文件夹名相同。
3. **没重启**：技能列表是启动时加载的，装完必须重启会话。
4. **工具不支持 Skill 机制**（比如 ChatGPT 网页版）：把 `SKILL.md` 正文整段复制进去当提示词也能用，只是没有自动触发。

## 怎么用

装好之后不需要敲任何命令，说一句触发的话就行：

- 「帮我改选题：小个子穿大衣怎么不显高」
- 「用三维分析法看看我这个选题能拍吗」
- 「我选题没流量 / 不知道拍什么 / 内容没人看」
- 「我的用户到底想要什么」

它会走完这一整套：

```
开场（说明它不替你填，只追着问）
  → 第 0 步：轻判断，这算不算一个选题（需求 + 供给 + 话题）
  → 第一维：身份标签 → 痛感人群 → 主观感受人群
  → 第二维：列情绪 → 追情绪对象 → 追后果，翻译成人性需求
  → 第三维：需求 × 情绪价值 / 实用价值
  → 组合：一批选题树
  → 收尾：分清选题 / 钩子 / 脚本
```

**用的时候记住三点**：

1. **它慢是故意的**。每次只问一个环节，是为了让你真的想下去。你答得快、答得表面，它会在原地再追一两轮。
2. **别把"状态"当"需求"交上去**。"存不下钱""孩子不听话"是现状，不是真需求，真需求是"他为什么在乎这个"。
3. **它不评判你的价值观**。它只判断这条选题是不是比之前更对准需求、更有人看。

## 适合谁 / 不适合谁

**适合**：做知识型内容、口播、账号定位不清、选题老是"自嗨"、发了很多条但没流量的创作者。

**不适合**：已经很清楚自己用户是谁、只差一个标题的人——那是钩子的活，不是选题的活。
